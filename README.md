# Yossi Manzur — Minimal Homepage

Framework-free static site for `yossimanzur.com`.

## Cloudflare Pages settings

- Production branch: `main`
- Build command: `exit 0`
- Build output directory: `.`

After the first deploy, add `yossimanzur.com` under the Pages project's **Custom domains**.

Before publishing, confirm the GitHub link is correct:
`https://github.com/yossimanzur`

The public site intentionally omits a phone number.
